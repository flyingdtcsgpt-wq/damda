# 담다

일기 · 글 · 글쓰기 자료 · 계획서 · 할 일 · 이미지 · 녹음 · 링크를 한곳에 담는 개인용 노트.
내용은 기기 안에서 암호화(AES-256)되고, 동기화 서버에는 암호화된 덩어리만 올라갑니다.

## 설치형 앱 (권장)

GitHub 저장소의 **Releases**에서 기기에 맞는 파일을 받아 설치합니다. 서버 없이 바로 쓸 수 있고, 동기화는 필요할 때만 연결합니다.

| 기기 | 파일 |
|---|---|
| Windows | `Damda Setup x.y.z.exe` |
| Mac | `Damda-x.y.z-arm64.dmg`(애플 칩) / `Damda-x.y.z.dmg`(인텔) |
| Linux | `Damda-x.y.z.AppImage` |
| Android | `damda-android.apk` |

서명되지 않은 앱이라 처음 설치할 때 "확인되지 않은 개발자" 경고가 뜹니다. iPhone은 아래 웹 방식으로 씁니다.

새 버전 만들기: `package.json`의 version을 올리고, GitHub의 Actions → "설치 파일 만들기" → Run workflow를 누르면 설치 파일이 만들어져 Releases에 올라갑니다.
개발 중 실행: `npm install` 후 `npm start`.

## PC 한 대에서만 쓰기 (서버 없음)

`담다-열기.html`을 더블클릭하면 끝입니다. 설치도 서버도 인터넷도 필요 없습니다.
즐겨찾기(북마크)에 넣어 두고 쓰세요.

- 데이터는 그 브라우저 안에 암호화되어 저장됩니다. **브라우저의 "인터넷 사용 기록 삭제"에서 사이트 데이터를 지우면 함께 지워지니**, 설정 → 백업에서 백업 파일을 가끔 내려받아 두세요.
- 폴더를 다른 위치로 옮기지 마세요. 옮긴 뒤 내용이 안 보이면 원래 위치로 되돌리거나 백업 파일로 복원하면 됩니다.
- 나중에 동기화가 필요해지면 아래처럼 서버를 띄우고 설정 → 동기화에 주소를 넣으면 지금까지 쓴 내용이 그대로 올라갑니다.

## 서버 설치 (한 곳에만 하면 됩니다)

집에서 늘 켜 두는 기기 하나를 고르세요. Node.js가 없어도 처음 실행할 때 자동으로 받아 옵니다.

| 기기 | 방법 |
|---|---|
| Windows | `start-windows.bat` 더블클릭 |
| Mac | `start-mac.command` 더블클릭 (처음엔 우클릭 → 열기) |
| Linux | `./start.sh` |
| NAS · Docker | 이 폴더에서 `docker compose up -d` |

브라우저에서 http://localhost:8787 이 열립니다. 데이터는 이 폴더의 `data/`에 쌓이니 이 폴더만 백업하면 됩니다.

## 다른 기기(휴대폰 등)에서 접속

휴대폰에서 설치·녹음·오프라인 사용을 하려면 **https 주소**가 필요합니다. 가장 쉬운 방법은 Tailscale(무료)입니다.

1. 서버 기기와 휴대폰에 Tailscale을 설치하고 같은 계정으로 로그인
2. 서버 기기에서 `tailscale serve --bg 8787` 실행 → `https://기기이름.xxx.ts.net` 주소가 생김
3. 그 주소를 휴대폰 브라우저에서 열고 앱 설치

그다음:

1. 첫 기기: 설정 → 동기화 → 그 https 주소 입력 → "코드 복사"
2. 다른 기기: 첫 화면 "다른 기기에서 쓰던 보관함 연결" → 코드와 암호 입력

## 설치

- Windows · Mac: Chrome/Edge 주소창의 설치 아이콘
- iPhone · iPad: Safari 공유 → 홈 화면에 추가
- Android: Chrome 메뉴 → 앱 설치

## 암호와 복구

- 암호는 선택입니다. 없이 쓰다가 나중에 걸 수 있고, 다시 없앨 수도 있습니다.
- 한 번 풀면 유지되는 시간: 바로 잠금 / 1시간 / 8시간 / 1일 / 3일 / 7일 / 30일
- 암호를 잊으면 **복구 키(25자)** 로 새 암호를 정합니다. 복구 키까지 잃으면 누구도 복구할 수 없습니다.
- 설정 → 백업에서 암호화된 백업 파일을 가끔 내려받아 두세요.

## 보안

- 내용은 기기에서 AES-256-GCM으로 암호화됩니다. 암호는 Argon2id(메모리 64MB)로 변환합니다.
- 암호를 5번 틀리면 30초부터 두 배씩(최대 1시간) 기다려야 합니다.
- 지문·얼굴 잠금 해제: 설정 → 잠금에서 켭니다. https 주소나 localhost로 열었을 때, 지원하는 기기에서만 됩니다.
- 서버는 기본으로 **처음 연결한 보관함 하나만** 받습니다. 가족 등과 함께 쓰려면 `MAX_VAULTS=3`처럼 늘려 실행하세요.
- 서버 접속 제한: IP당 분당 1200회(`RATE_PER_MIN`), 인증 실패가 10분에 20번이면 10분간 차단. 프록시 뒤라면 `TRUST_PROXY=1`.
- 보관함을 새로 만들어 서버에 다시 연결하려면 서버의 `data/` 폴더를 비우거나 `MAX_VAULTS`를 늘려야 합니다.
